# Template Maintenance Agreements

## Purpose

This file defines how reusable changes should be promoted into the canonical PROAD template.

## Agreements

- Promote reusable structure, agreements, instructions, and bootstrap patterns into the template.
- Do not copy current-project names, statuses, dates, paths, or examples into template content.
- Update relevant indexes and entry-point documents whenever the template structure changes.
- Ask the smallest question needed when it is unclear whether a change is local or reusable.
