# Session Bootstrap

## Purpose

Define the mandatory session-start material the AIA must load before doing work in a PROAD project created from this template.

## Bootstrap Order

1. Read [`global-working-agreements.md`](./global-working-agreements.md).
2. Read [`roadmap-agreements.md`](./roadmap-agreements.md).
3. Read [`file-naming-standard.md`](./file-naming-standard.md).
4. Read [`../index.md`](../index.md).
5. Read [`index.md`](./index.md).

## Session Start Outcome

After loading the bootstrap documents, the AIA should:

- operate in read-only mode until the active project's approval model allows execution
- understand the purpose and structure of the project workspace before storing or linking information
- keep roadmap content minimal and route detailed information into `docs/`
- avoid guessing filenames, destinations, metadata shape, or linkage
