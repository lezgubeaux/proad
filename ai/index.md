# AI

## Purpose

This folder stores AI-facing operating documents for PROAD.

These documents define how the AIA should start a session, what rules apply globally, and how repository behavior should remain deterministic.

## Entry Points

-   [`file-naming-standard.md`](./file-naming-standard.md) defines filename rules.
-   [`global-working-agreements.md`](./global-working-agreements.md) stores repository-wide agreements and limitations.
-   [`notes-agreements.md`](./notes-agreements.md) defines how notes should be documented, split, and referenced.
-   [`proad-basics.md`](./proad-basics.md) explains the purpose, structure, and operating model of PROAD.
-   [`proad-release-agreements.md`](./proad-release-agreements.md) defines how approved template states become standalone PROAD releases.
-   [`roadmap-agreements.md`](./roadmap-agreements.md) defines roadmap-related agreements.
-   [`session-bootstrap.md`](./session-bootstrap.md) defines the session-start loading order for PROAD.
-   [`supporting-material-agreements.md`](./supporting-material-agreements.md) defines how supporting-material hubs should work.
-   [`template-maintenance-agreements.md`](./template-maintenance-agreements.md) defines how reusable changes are promoted into the template.
