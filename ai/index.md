# AI

## Purpose

This folder stores AI-facing operating documents for PROAD.

These documents define how the AIA should start a session, what rules apply globally, and how repository behavior should remain deterministic.

## Entry Points

-   [`context-agreements.md`](./context-agreements.md) defines how optional project-context files are identified, presented, maintained, and supplied to the AIA.
-   [`development-backlog.md`](./development-backlog.md) stores deferred, prospective, and unfinished PROAD framework work.
-   [`development-host-transfer-agreements.md`](./development-host-transfer-agreements.md) defines safe transfer of the single active development-host role.
-   [`file-naming-standard.md`](./file-naming-standard.md) defines filename rules.
-   [`global-working-agreements.md`](./global-working-agreements.md) stores repository-wide agreements and limitations.
-   [`template-management-agreements.md`](./template-management-agreements.md) defines promotion, installation, and update behavior for `project/` files.
-   [`work-lifecycle-and-archiving-agreements.md`](./work-lifecycle-and-archiving-agreements.md) defines cleanup, consolidation, archival, removal, reference maintenance, and verification across completed or inactive work.
-   [`notes-agreements.md`](./notes-agreements.md) defines how notes should be documented, split, and referenced.
-   [`proad-basics.md`](./proad-basics.md) explains the purpose, structure, and operating model of PROAD.
-   [`project-core-documents-agreements.md`](./project-core-documents-agreements.md) defines the standard project overview and project changelog responsibilities.
-   [`project-resources-agreements.md`](./project-resources-agreements.md) defines reusable handling of client-owned project resource hubs.
-   [`project-migrations.md`](./project-migrations.md) defines reviewed version-specific project changes that accompany framework updates.
-   [`proad-release-agreements.md`](./proad-release-agreements.md) defines how approved template states become standalone PROAD releases.
-   [`raw-agreements.md`](./raw-agreements.md) defines zero-friction pre-classification capture, quiet handling, selective rummaging, and Raw promotion safety.
-   [`roadmap-agreements.md`](./roadmap-agreements.md) defines roadmap-related agreements.
-   [`session-bootstrap.md`](./session-bootstrap.md) defines the session-start loading order for PROAD.
-   [`scripts/`](./scripts/index.md) contains tested automation for deterministic PROAD operations.
-   [`supporting-material-agreements.md`](./supporting-material-agreements.md) defines how supporting-material hubs should work.
-   [`template-maintenance-agreements.md`](./template-maintenance-agreements.md) defines how reusable changes are prepared live and incorporated during version promotion.
