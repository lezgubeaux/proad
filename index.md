# PROAD Template

## Purpose

This folder is the canonical starter structure for new PROAD projects.

It should remain generic, reusable, and free of project-specific information.

## Entry Points

- [`README.md`](./README.md) provides the root-level overview for the installed PROAD workspace.
- [`CHANGELOG.md`](./CHANGELOG.md) is reserved for published standalone PROAD version history.
- `developer/` contains human-facing guidance for working with PROAD itself as a framework.
- `project/` stores the human-facing starter workspace.
- `docs/` stores the AI-managed starter knowledge repository.
- `ai/` stores the starter agreements, bootstrap material, and standards for a new PROAD project.
