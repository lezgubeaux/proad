# Project Resources

## Purpose

This folder stores project-specific resource entries and expanded operational resource records that have grown too long for the corresponding section in [`entry-points.md`](./entry-points.md).

The main resource file remains the primary access point. When an entry grows into an expanded record, its section in `entry-points.md` should retain a short explanation and a link to that record.

## Entry Points

Project-specific expanded-resource links are stored in [`entry-points.md`](./entry-points.md).
