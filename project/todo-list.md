# Todo List

## Purpose

This file tracks operational tasks that support the project work but do not belong in the roadmap as top-level project steps.

## Usage

- Use this list for concrete operational tasks, maintenance, setup work, and other supporting actions.
- Store project-specific tasks in [`todo-list-tasks.md`](./todo-list-tasks.md).
- Keep outcomes and meaningful project progression in [`roadmap.md`](./roadmap.md).
- Link supporting documents or material when a task needs additional context.
- Move a task to the roadmap when it becomes a meaningful project stage or outcome.
