# Graphic Assets

## Purpose

This folder stores editable graphic sources and export masters used during project work.

Project-specific categories may use their own approved folders under `graphics/`. This folder remains the general location for working graphic assets that do not belong to one of those categories.

Production-ready assets consumed by a website or application belong in that project's live implementation files, not in PROAD.
