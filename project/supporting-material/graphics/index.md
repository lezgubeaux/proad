# Working Graphics

## Purpose

This folder stores non-deployable working graphics that support project design and implementation.

Use [`assets/`](./assets/) for editable graphic sources and export masters unless an approved project-specific category has its own folder.

Production-ready assets consumed by a website or application belong in that project's live implementation files, not in PROAD.

## Git Behavior

Ordinary files below this folder are intentionally ignored by Git.

Directories, the local `.gitignore`, and every nested `index.md` remain trackable. Nested index files may document meaningful project-specific subfolders without turning indexes into complete graphic-file catalogs.
