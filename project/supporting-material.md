# Supporting Material

## Purpose

This file lists non-deliverable but important project-support materials.

These materials may support page composition, content work, design, web development, validation, or other project activity without being deliverables themselves.

When supporting files belong inside this project workspace, the preferred local location is [`supporting-material/`](./supporting-material/).

## How To Use This File

Each entry in [`supporting-material-entries.md`](./supporting-material-entries.md) should identify:

- what the material is
- where it is
- why it matters

Use this file as the human-facing hub.

Store local supporting artifacts in [`supporting-material/`](./supporting-material/) when that keeps the project workspace clearer, then link them from this file.

## Entries

Project-specific supporting-material entries are stored in [`supporting-material-entries.md`](./supporting-material-entries.md).
