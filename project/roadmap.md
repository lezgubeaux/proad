# Project Roadmap

## About This Roadmap

This roadmap is the primary human-facing view of the project's progress.

It should remain concise, readable, and focused on the project path.

Each roadmap item should contain only:

- a stable identifier
- a clear step or outcome name
- a short description
- a current status
- links to supporting documents when needed

Sub-steps may be used when a top-level step contains meaningful internal progression.

Detailed explanations, research, working notes, decisions, implementation plans, and historical records should not be stored directly in the roadmap.

They belong in `docs/` and may be linked from the relevant roadmap item.

## Human Use

Use this roadmap to understand:

- what the project is trying to achieve
- what has already been completed
- what is currently active
- what is expected next
- which supporting records are relevant

The roadmap is not expected to contain every task or piece of project knowledge.

## Status Values

Use only the project's agreed status values.

When no project-specific status model exists, use:

- planned
- in-progress
- blocked
- completed
- cancelled
